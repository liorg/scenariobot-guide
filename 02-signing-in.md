# 02. Signing in

**How to get there:** open the site. If you're not signed in you land here
automatically.

**URL:** [grossman.bot/](https://grossman.bot/)

## First screen

Signed out, you see the landing page with a **Log in** button. Pressing it opens
the sign-in form.

## Signing in

Three ways, all on the same screen:

- **Email and password.**
- **A magic link** — leave the password box empty and you get a sign-in link by
  email, valid for 60 minutes.
- **Google or GitHub** — the two buttons below the divider.

### Signing in with GitHub

Press **GitHub** and approve the access request. GitHub asks for your profile
and your email address; the email is needed because an account here is
identified by it, and GitHub does not share it otherwise if you have hidden it
on your profile.

If your GitHub profile has no display name, you appear under your GitHub
username until you set a name in Settings.

**The method you first signed up with is the one to keep using.** Signing in
with GitHub and with email are different routes into the same account only when
they carry the same address.

## New accounts

A new account confirms by email before first use. Check the inbox for the
confirmation link — until it's clicked, the password won't work.

## Forgotten password

**Reset password** is on the login screen. You'll get an email with a link; the
link opens a screen where you set a new one and are then signed in.

## Signing out

**Logout** is at the far end of the top bar, next to your avatar.

## After signing in

You land on `/phones`. From there every screen has its own address — see
[the map](README.md#every-screen-has-an-address). If you open a saved link
while signed out, you are asked to sign in and then taken to it.

## Privacy policy

Linked in the footer of every page, and reachable at `/privacy` without signing
in.
